# PCB Viewer part library

Two ready-made bundles that give every common through-hole / SMD part a real footprint, a
schematic symbol, a real 3D body and a manufacturer datasheet link — no network needed at
run time.

| File | Contents |
|---|---|
| `pcbv-starter.pcbvlib` | 12 footprints (pads, tracks, arcs, regions) + **12 real STEP bodies** + datasheet link, manufacturer and MPN for each part |
| `pcbv-symbols.pcbvlib` | 12 matching schematic symbols (body, pins, numbers, names) |

## Parts

| Part | Kind | Datasheet |
|---|---|---|
| `TO-252-2` | DPAK / TO-252 transistor or regulator | Vishay D-PAK (TO-252AA) |
| `DO-41` | DO-41 / SOD-81 axial diode, 10.16 mm pitch | Vishay 1N4001…1N4007 |
| `R-Axial-DIN0207` | axial resistor, 6.3 × 2.5 mm body | Vishay BCcomponents PR01/02/03 |
| `CP-Radial-D8-P3.5` | radial electrolytic capacitor, 8 mm can | Panasonic radial lead type |
| `LED-5MM` | 5 mm through-hole LED | Kingbright WP7113SRD/D |
| `HDR-1X04-2.54` | 1×4 pin header, 2.54 mm | Würth Elektronik 61300411121 |
| `SOT-23` | SOT-23 3-lead | onsemi CASE 318 |
| `SOIC-8` | SOIC-8, 3.9 × 4.9 mm, 1.27 mm pitch | onsemi CASE 751AZ |
| `R-0603`, `R-0805` | chip resistors | Vishay D/CRCW e3 |
| `C-0603`, `C-0805` | chip capacitors | KEMET X7R SMD |

Every datasheet link above is a real URL that was opened while this library was built;
`pcbv-cli --lib <file>` prints the same links so they can be checked at any time.

## How the viewer picks them up

Open a board and the viewer looks for library bundles in this order:

1. the folder of the board itself,
2. `<board folder>/library`,
3. `$PCBV_LIBRARY` (a file or a folder),
4. `./library` (the working directory, i.e. the repository),
5. `~/.local/share/pcbv/library`.

A part gets a model only when the footprint really matches: the footprint name is compared
first (ignoring case and separators, plus a fingerprint of pad count / pad extents / hole
sizes), and geometry is used only when exactly one library part wins within ±15 % size. So a
board that names its footprints differently — `DPAK`, `DO41`, `AXIAL-0.4`, `CAP-8x12` — still
gets the right DPAK, DO-41, axial resistor and 8 mm electrolytic bodies.
